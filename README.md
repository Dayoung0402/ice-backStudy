### 1️⃣ 브랜치 용도

1. 각자 이름의 브랜치 → Common 내용에 제시된 핵심 키워드 공부 내용
- common 내용이란, Back, Front 개발자 모두 알아야 한다고 알려주신 주제들
1. Code 브랜치 → 간단한 프로젝트 내용이 담긴 브랜치
- 협업 할지 아니면 개별로 만들어 볼지… 고민중 😑
1. 각자 추가로 만든 브랜치 → 추가로 공부하고 싶은 부분 공부하고 공유
