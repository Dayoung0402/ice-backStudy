# DBMS → RDBMS(mySql)

---

### 1. DBMS (Data Base Management System)

- 데이터 베이스 관리 시스템이라고 번역할 수 있는데, 말 그대로 데이터들이 저장된 저장소인 데이터 베이스에 접근하여 데이터의 집합을 만들고 관리하는 시스템이라고 이해할 수 있음
- 사람이 데이터베이스를 다루기 위해서 데이터베이스 관리 시스템인 DBMS가 필요한 것

→ 🙆‍♀️(사람) ——— 🔗(데이터베이스관리시스템) ———> 🥅(데이터베이스)

- 사용자는 DBMS에서 제공하는 SQL 인터페이스를 이용해서 데이터베이스에 접근
- SQL(structured Query Language) : DB에 데이터 정보를 조회, 생성, 수정 하기 위한 표준 언어
- SQL 인터페이스 : 사용자가  SQL 명령어를 **입력하고 실행할 수 있도록 제공되는 창구**
    
     **→**  이 인터페이스를 통해 SQL 문을 DBMS에 전달하는 것
    

### 2. RDBMS : 관계형 데이터 베이스 시스템

- 관계형 데이터 베이스 시스템 : 데이터를 행과 열이 있는 테이블 형식으로 저장
    
    cf) 비관계형 데이터 베이스 시스템 : 데이터 단독 저장
    

| 관계형 데이터 베이스 | 비관계형 데이터 베이스 |
| --- | --- |
| mySQL | NoSQL, Redis |

### 3. mySQL과 인텔리제이/VS Code 연결

- 컴퓨터에 mySQL을 설치하는 것과 별개로 인텔리제이/VS Code와 같은 툴에 DB를 연결 필요
- 터미널에 다음 명령 실행 후 mySQL 비번 입력

<aside>

mysql -u root -p

</aside>

- case 1 : 인텔리제이 내에서 DB 창 사용 → GUI 환경에서 DB를 접속 → DB 접속, 테이블 조회, 쿼리 실행
- case 2 : 터미널을 열어서 직접 SQL 명령 실행
    
    → case 1은 시각적 확인 편함(툴 내부에 DB 관리할 수 있는 부분이 있기 때문에)
    
    → case 2는 시각적 확인이 불가능하고(터미널에 입력해서 DB에 명령을 주는 거기 때문에 반복 작업이 이루어 질 때, DB에 저장된 데이터 수정이 필요한 상황에서 불편)
    
    💡 case 1 방법으로 DB 제어하는 것이 편함
    
- DB에 프로젝트에 필요한 스키마 생성 → 스키마 내부에 Query에 DDL, DML, DCL 파일 만들어서 각 파일의 기능별로 필요한 SQL 구문을 작성해서 실행시키면 DB에 반영됨
- 이때 작성한 DDL, DML, DCL 파일 내의 구문들은 삭제 시켜도 DB정보에는 무방
    
    → 이 파일들을 삭제시킨다고 DB정보가 삭제되는 것이 절대 아님
    
    → DB의 테이블의 정보들을 수정하고 싶으면 DML 파일을 열어서 필요한 SQL 구문을 작성한 다음에 실행시키면 됨
